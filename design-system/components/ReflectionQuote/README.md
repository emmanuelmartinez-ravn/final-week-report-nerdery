# ReflectionQuote

Highlights a piece of mentor feedback or a personal key insight inside an entry.

**Markup:** `<figure class="rj-quote">` › `<blockquote>` + `<figcaption>` (`.rj-avatar` initials + name · role). Use the real quote with the mentor's permission.

**Tokens:** `bg-subtle`, `radius-lg`, padding `space-6`; quote `body-lg` in `text-primary`; caption `body-sm` `text-secondary`; avatar `tag-bg`/`tag-text`.

## Do
- One quote per entry, at most — it should feel earned.

## Don't
- Don't add a coloured left bar or giant quotation-mark graphics.
- Don't invent or paraphrase feedback as a quote.
