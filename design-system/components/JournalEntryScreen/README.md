# JournalEntryScreen

Example screen: one weekly entry — TOC on the left, the reflection capped at `reading-max` (680px) in the middle, an "At a glance" card on the right.

Built from Navigation (TOC), Tag, Alert, ReflectionQuote, ModuleProgress (steps), Card (pager). Code blocks use `code` type on `bg-subtle`. Below `screen-lg`, the TOC and side card move above the article.
