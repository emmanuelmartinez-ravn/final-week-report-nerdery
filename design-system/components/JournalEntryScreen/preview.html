Journal Week 06

Shipping a GraphQL API

Sep 22–26, 2026 6 min read
GraphQLApollo ServerPostgreSQL

This week I moved the Bookshelf backend from REST to GraphQL. The schema took an afternoon; making it fast took the rest of the week.

What I built

A schema for books, readers and reviews, with resolvers backed by Prisma. The first version worked — and fired 41 SQL queries for a single page of reviews.

const bookLoader = new DataLoader(ids =>
  prisma.book.findMany({ where: { id: { in: ids } } }));

Batching with DataLoader brought that down to 6.

What I learned

  • Write the query you want the client to send before the schema.
  • Resolvers are small functions — test them like functions.
  • Measure first: I only found the N+1 because I logged every query.

Still open

Pagination uses offsets; I want to switch to cursors next week.
