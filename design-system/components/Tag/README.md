# Tag

A small, non-interactive pill for a topic, module or status.

**Markup:** `<span class="rj-tag">GraphQL</span>`; variants `rj-tag-accent` (current/active), `rj-tag-neutral` (draft, meta), `rj-tag-success` (done — with icon). Wrap groups in `.rj-tags`.

**Tokens:** `tag-bg` + `tag-text` (secondary/indigo, ≥ 7:1), `radius-full`, `caption` weight 600.

## Do
- Keep to one or two words, Title Case for technologies as they brand themselves ("Node.js", "PostgreSQL").

## Don't
- Don't make tags clickable; for filters use Checkbox or a Select.
- Don't use more than four tags on one card.
