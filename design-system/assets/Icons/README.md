# Icons

24 Lucide icons (ISC licence) at 1.75px stroke, drawn in `neutral-950` ink (#0d0d0d). Use these `<img>` files only on light grounds (`bg-canvas`, `bg-surface`). In UI, inline the same Lucide SVG with `stroke="currentColor"` so it follows `text-*` and `accent-text` tokens in both themes. Meanings are fixed: info, circle-check (success), triangle-alert (warning), circle-x (error), folder-git-2 (repository), external-link, calendar (date), clock (duration), notebook-pen (journal entry), lightbulb (key learning), message-square (mentor feedback).
